# BCBA Case Study Simulation Exam — Design Ideas

## Approach 1: Clinical Precision (Probability: 0.07)
**Design Movement:** Medical/Clinical Modernism
**Core Principles:** Structured grid, high information density, clinical authority, data-forward
**Color Philosophy:** Deep navy (#0f2044) with white and slate grays; teal (#0d9488) as accent for correct answers; rose for incorrect. Evokes clinical trust and precision.
**Layout Paradigm:** Left sidebar for case file navigation, main content area for questions, right panel for progress metrics
**Signature Elements:** Horizontal rule separators with domain labels, monospaced data tables for client info, progress bar with domain breakdown
**Interaction Philosophy:** Deliberate, no animations — each click is a clinical decision
**Animation:** Minimal — only fade-in for new content
**Typography:** DM Sans (body) + Playfair Display (headers) — authoritative yet readable

---

## Approach 2: Academic Warmth (Probability: 0.06)
**Design Movement:** Editorial / Academic Publishing
**Core Principles:** Warm cream tones, generous margins, typographic hierarchy, case-file aesthetic
**Color Philosophy:** Warm cream (#faf7f2) background, deep forest green (#1a3d2b) for primary text and actions, amber (#d97706) for highlights. Feels like a well-worn textbook.
**Layout Paradigm:** Single-column centered layout with wide margins; case narrative displayed as a "file card" pinned at the top; questions flow below
**Signature Elements:** Left-border accent lines for case scenario blocks, serif drop caps for domain headers, paper-texture background
**Interaction Philosophy:** Reading-first — the case narrative is always visible; questions feel like annotations
**Animation:** Gentle slide-up for new questions, smooth progress fill
**Typography:** Lora (serif, for case narrative) + Source Sans Pro (for questions and UI) — academic gravitas

---

## Approach 3: Modern Clinical Dashboard (Probability: 0.08)
**Design Movement:** Functional Brutalism meets Healthcare UX
**Core Principles:** Bold typography, high contrast, asymmetric layout, clinical data visualization
**Color Philosophy:** Off-white (#f8f9fa) background with charcoal (#1c1c1e) text; electric blue (#2563eb) for primary actions; emerald for correct, red for incorrect. Clean, modern, professional.
**Layout Paradigm:** Sticky top header with case summary; two-column layout — case file on left (collapsible), questions on right; bottom progress bar
**Signature Elements:** Domain phase indicator (timeline at top), client profile card with avatar, answer choice cards with hover lift effect
**Interaction Philosophy:** Gamified but professional — instant feedback, domain progress tracking, score animation
**Animation:** Answer cards flip/highlight on selection, progress bar animates on advance, smooth transitions between questions
**Typography:** Space Grotesk (headers, bold) + Inter (body) — modern clinical feel

---

## Selected Approach: **Approach 2 — Academic Warmth**

The editorial, case-file aesthetic is the most appropriate for this application. It reinforces the "reading a case" experience, which is the core pedagogical intent. The warm cream tones reduce eye strain during a long exam, the serif typography for case narratives adds clinical gravity, and the generous margins ensure the dense question content is readable. The left-border accent on scenario blocks visually separates the "case" from the "question," which is critical for the application-level cognitive task being asked of the user.
